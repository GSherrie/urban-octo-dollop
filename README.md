## Projects

### SherPay (`sherpay/`)

Invoice, expense, and cash-flow app for freelancers and SMEs (Ghana-first: GHS, MoMo, bank transfer).

- **Source:** [`sherpay/`](./sherpay)
- **Live (existing):** [https://sherpay.vercel.app](https://sherpay.vercel.app)
- **Vercel project:** [gsherries-projects/sherpay](https://vercel.com/gsherries-projects/sherpay)

```bash
cd sherpay
npm install
npm run dev    # http://localhost:3000
npm run build
```

**Deploy to Vercel**

1. In the Vercel project **sherpay**, set **Root Directory** to `sherpay`.
2. Connect this GitHub repo (`GSherrie/urban-octo-dollop`) if it isn’t already.
3. Deploy the branch that contains the rebuild (or merge to the production branch).

Or from the CLI (logged into the `gsherries-projects` team):

```bash
cd sherpay
npx vercel --prod
```

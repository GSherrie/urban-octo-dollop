# SherPay — Invoicing, Receipts & Payments

Mobile-first web app for creating invoices, getting paid, scanning receipts and exporting tax-ready data.
Branded with the SherPay logo (`assets/logo.png`) — navy/blue/green design language carried through the UI, invoice templates and receipts.

## Run it

```bash
cd sherpay
python3 -m http.server 8000 --bind 0.0.0.0
# open http://localhost:8000
```

Any static server works — the app is dependency-free (vanilla JS, no build step, offline-first via localStorage).
Regression tests: `node smoke.js` (dependency-free route render check) and `node test-ui.js` (jsdom — clicks through editor, pay flow, OCR scan, timer, CRM, settings; needs `npm i jsdom`).

## Use it on your phone (PWA)

SherPay is an installable Progressive Web App: `manifest.json` + service worker (`sw.js`) + home-screen icons generated from the logo (`assets/icon-192/512/maskable.png`, `apple-touch-icon.png`).

- Serve it over any HTTPS URL (the sandbox preview proxy is token-locked, so for ad-hoc phone access run a tunnel: `/tmp/cloudflared tunnel --url http://127.0.0.1:8000` and open the printed `*.trycloudflare.com` URL).
- **Android (Chrome):** menu → *Add to Home screen / Install app* → launches full-screen, works offline after first load.
- **iPhone (Safari):** Share → *Add to Home Screen* → same standalone experience with the SherPay icon.
- Data lives in the phone browser's localStorage (offline-first); it is separate per device/browser.

## Single-file mobile build (no server needed)

`node scripts/build-mobile.js` inlines all CSS/JS and the logo (base64) into one self-contained
`SherPay-mobile.html` (~1.3 MB). Download it to any device and open it in a browser — fully offline,
no tunnel, no install. Verified by `test-mobile.js` (jsdom boot + render check).
A true App Store `.ipa` additionally requires an Apple Developer account and Xcode on macOS to sign;
the web app in this repo is Capacitor/Cordova-ready if you want to wrap it later.

## The MVP core loop (all live)

1. **Create** — `Invoices → New invoice`: client auto-fill from CRM, flexible line items, % or flat discount, % or flat tax (VAT/GST/Sales Tax label configurable), 12 currencies, sequential numbering (`INV-2026-001`, prefix customizable), monthly recurring option.
2. **Send** — email / WhatsApp / SMS pay-link + copy-link; opening the link flips status **Sent → Viewed** automatically.
3. **Track** — statuses Draft · Sent · Viewed · Partially paid · Overdue · Paid; **Pay Now** checkout simulates Stripe card, PayPal, Apple Pay, Mobile Money & bank transfer, including partial payments/deposits; automatic payment reminders (X days before / on / after due) land in the Settings outbox; recurring invoices auto-generate.
4. **Receipt** — paying in full auto-generates a branded **Paid receipt** (RCP-…) and emails it (logged in Activity).
5. **Scan** — `Expenses → Scan receipt`: simulated OCR (upload a photo/PDF or run the demo scan) extracts merchant, date, category, tax & total for review; attachments (PDF/JPEG) stored with the expense; category totals for tax deductions.
6. **Export** — one-click PDF (print-rendered invoice/receipt/report), CSV for invoices, expenses, P&L and a categorised tax report; full JSON backup/restore.

## Everything else in the build

- **Dashboard** — outstanding, collected, expenses, net-profit KPIs; 6-month cash-flow chart; status pipeline donut; ageing list; auto-logged activity feed.
- **Clients (CRM)** — contact, billing address, payment terms (auto-fill due dates), per-client billed/outstanding totals, one-click invoice.
- **Time tracking** — stopwatch → billable entries → converted into draft invoice line items at the configured hourly rate.
- **Reports** — P&L by month, tax collected vs recoverable, expense categories, accountant-ready CSVs.
- **Templates** — 5 brand accents × 3 fonts, uploadable logo, business profile printed on every document.
- **UX** — mobile bottom-nav layout, search + status filters, offline indicator (data stays on-device, syncs on reconnect), toasts, empty states.
- **Pro tier (locked, shown in app)** — GPS mileage tracker, inventory, client portal, QuickBooks/Xero sync, biometric login.

## Architecture

```
sherpay/
  index.html          shell + boot splash
  styles.css          design system, print styles, responsive/mobile nav
  assets/logo.png     SherPay logo (sidebar, favicon, invoices, receipts)
  js/store.js         persistence (localStorage), seed demo data, money/date utils,
                      totals engine, numbering, reminders + recurring automations, CSV/JSON export
  js/ui.js            router, sidebar/bottom-nav shell, icons, modals, toasts, SVG charts
  js/views-main.js    dashboard, invoice list, client pay-link view, receipt view, send/pay modals
  js/views-editor.js  invoice editor (line items, tax/discount, currency, recurring)
  js/views-ops.js     clients CRM, expenses + OCR scan, time tracking
  js/views-biz.js     reports (P&L/tax/exports), settings (branding, defaults, automations, data)
```

Data model: `settings · clients · invoices(items, payments) · expenses(attachment) · timeEntries · activity` in one versioned localStorage key (`sherpay_db_v1`), seeded with a realistic demo book (GHS/USD invoices across all statuses).
